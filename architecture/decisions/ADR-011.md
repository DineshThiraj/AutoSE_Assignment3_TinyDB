# ADR-011 · Independent test evidence

## Status

Retrospective implementation record, 20 November 2026. Student review pending. Refines the mechanism under [ADR-007](ADR-007.md). The original ADR retains its decision and chronology.

## Context

The old acceptance gate could accept a successful candidate-produced report without executing the stated checks. A controlled local test reported 229 successes and ran zero assertions. This contradicted the original goal of independently verifying execution.

## Decision

Treat candidate XML as diagnostic. Assign verdict authority to the trusted supervisor outside the candidate container. Execute pinned tests and restricted generated tests in separate sessions, using the worker only for constrained TinyDB operations. Bind the verdict to the candidate and environment identities, case inventory and verified completion. Require separately trusted exact-head CI for hosted release.

## Consequences

A real local Docker run accepted 228 baseline plus four generated tests and rejected an unfixed defect and a forged-result case. The negative controls differ across versions. The compatibility profile and hosted provenance remain limited. The protected check issuer and dispatch lifecycle remain undeployed. See [experiment E1](../../experiment/variants.md).
