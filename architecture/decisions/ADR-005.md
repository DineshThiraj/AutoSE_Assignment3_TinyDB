# ADR-005: Tools

## Status

Accepted — student choice supplied 2026-11-17. Initial reviewed decision; implementation and experimental evidence pending.

## Context

Generated TinyDB code and tests may be malicious and cannot execute with provider keys or repository write authority. Context prose and Nygard formatting are Codex assistance. The choice and quoted explanation below are transcribed from preparation/STUDENT_REVIEW.md (copied here as ../STUDENT_REVIEW.md).

## Decision

Restricted model-broker tools with isolated patch application, test execution and a separate GitHub publisher.

Student-supplied explanation, labelled “suggested reason” in the source:

> Untrusted generated code and tests must not execute with provider credentials or repository write authority

## Consequences

Accepted drawback, supplied by the student:

> Additional validation, isolation and artifact transfers.

Considered and rejected alternative:

> One general shell agent holding all credentials

Student-supplied reason for rejecting it:

> It creates unnecessary exposure to malicious code or prompt injection

No successful runtime or experiment result is claimed. See ../IMPLEMENTATION_CONTRACT.md for assistant-authored operational detail within these choices. If evidence invalidates the decision, retain this file, mark Superseded and add a replacement with observed evidence.
