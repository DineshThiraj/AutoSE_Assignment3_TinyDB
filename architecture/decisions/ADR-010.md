# ADR-010: Triggers

## Status

Accepted — student choice supplied 2026-11-17. Initial reviewed decision; implementation and experimental evidence pending.

## Context

A public fork admits untrusted issue authors and duplicate label/comment events. Context prose and Nygard formatting are Codex assistance. The choice and quoted explanation below are transcribed from preparation/STUDENT_REVIEW.md (copied here as ../STUDENT_REVIEW.md).

## Decision

Authorized maintainer-applied autose label or exact /autose issue comment, with permission checks and duplicate-event handling.

Student-supplied explanation, labelled “suggested reason” in the source:

> This provides a convenient GitHub trigger without allowing arbitrary issue authors to initiate costly work

## Consequences

Accepted drawback, supplied by the student:

> Additional authorization, concurrency and idempotency logic.

Considered and rejected alternative:

> Allowing every issue author to trigger the workflow

Student-supplied reason for rejecting it:

> Issue authorship does not establish current repository write permissions
